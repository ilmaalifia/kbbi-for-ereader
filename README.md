# KBBI untuk E-Reader

Data kamus edisi Oktober 2026

Jumlah entri: 211.459

## Device: Kobo

File dapat diakses [di sini](https://github.com/ilmaalifia/kbbi-for-ereader/releases/tag/v1.0.0). 

Terdapat dua versi: berwarna (`dicthtml-id.zip`) dan tidak berwarna (`dicthtml-id.BW.zip`).

### Cara Menambahkan Kamus

1. Hubungkan device Kobo ke komputer
2. Copy file ke folder `.kobo/custom-dict/`, pastikan nama file telah diubah menjadi `dicthtml-id.zip`
3. Eject device Kobo dan KBBI siap digunakan
